# Pytest_CI_and_CD
Автоматизированное тестирование с помощью Pytest и CI/CD

## Инструкция:

1. **Создайте основной файл для тестирования**  
   В моём случае это `calculator.py`, где уже написаны все функции.  
   (Вы можете открыть файл и посмотреть код самостоятельно.)

2. **Создайте файл с тестами**  
   Добавьте второй файл для тестов, например `test_calculator.py`, где будут тесты Pytest для функций калькулятора.

3. **Настройте CI/CD**  
   GitHub сам по себе не запускает тесты, поэтому необходимо создать файл workflow:  

   Путь: `.github/workflows/test.yml`  

   Этот файл содержит конфигурацию для автоматического запуска тестов при каждом push.

4. **Зависимости**  
   В проекте есть файл `requirements.txt` с рекомендациями, что нужно установить, чтобы всё работало корректно.  
   Установите зависимости командой:  
   ```bash
   pip install -r requirements.txt
